# Быстрый старт: запуск SQL-тренажёра за 5 минут

Эта инструкция для тех, кто скачал проект с GitHub и хочет просто его
запустить. Python и PostgreSQL ставить **не нужно** — всё работает
внутри Docker. Нужны только две программы: **Git** и **Docker**.

Команды ниже нужно вводить в терминале:
- **Windows:** открой меню «Пуск», найди **PowerShell**, запусти.
- **macOS:** нажми `Cmd + Пробел`, введи **Terminal**, запусти.
- **Linux:** открой свой терминал.

Каждую команду копируй целиком и нажимай Enter.

---

## Шаг 1. Установи Docker (один раз)

1. Скачай **Docker Desktop** с сайта https://www.docker.com/products/docker-desktop/
   и установи как обычную программу (Linux: установи Docker Engine и
   плагин compose по инструкции с сайта docker.com).
2. **Запусти Docker Desktop** и подожди, пока внизу слева появится
   зелёный индикатор «Engine running». Если попросит перезагрузить
   компьютер — перезагрузи и снова запусти Docker Desktop.
3. Проверь в терминале:

```bash
docker --version
docker compose version
```

Обе команды должны показать номера версий. Если пишет
`command not found` или «не является командой» — закрой терминал,
открой заново. Не помогло — Docker не установился, повтори пункт 1.

## Шаг 2. Установи Git (один раз)

Проверь, есть ли он:

```bash
git --version
```

Если версия показалась — иди дальше. Если нет — скачай с
https://git-scm.com/downloads и установи со всеми настройками по
умолчанию.

## Шаг 3. Скачай проект

Замени `ССЫЛКА_НА_РЕПОЗИТОРИЙ` на адрес проекта на GitHub (кнопка
зелёная **Code** на странице репозитория, копируй ссылку `HTTPS`):

```bash
(ты это уже сделал)git clone ССЫЛКА_НА_РЕПОЗИТОРИЙ
cd sql_flashcards
```

Второй командой ты зашёл в папку проекта. (Если папка после
скачивания называется иначе, введи её настоящее имя после `cd`.)

## Шаг 4. Запусти

Находясь в папке проекта, введи:

```bash
docker compose up --build
```

Что произойдёт: Docker сам скачает всё нужное и запустит сайт и базу
данных. **Первый раз это занимает 1–3 минуты**, в терминале побегут
строки — это нормально. Ничего больше вводить не нужно.

Когда всё готово, в терминале будет что-то вроде:

```
app-1  |  * Running on http://127.0.0.1:5000
```

Терминал при этом **не вернёт тебе строку ввода — так и должно быть**:
пока он занят, программа работает. Не закрывай его.

## Шаг 5. Открой сайт

Открой в браузере: **http://localhost:5000**

Ты увидишь карточку с SQL-заданием. Пиши запрос в терминал на странице
и проверяй ответ.

## Как остановить

Вернись в окно терминала, где всё запущено, и нажми `Ctrl + C`. Потом
введи:

```bash
docker compose down
```

## Как запустить в следующий раз

Открой Docker Desktop (дождись зелёного индикатора), затем в
терминале:

```bash
cd путь/до/sql_flashcards
```

```bash
docker compose up
```

Слово `--build` нужно только в первый раз и после того, как ты что-то
поменял в проекте (код, карточки, схему).

## Если что-то пошло не так

| Что видишь | Что делать |
|------------|-----------|
| `Cannot connect to the Docker daemon` | Docker Desktop не запущен. Запусти и подожди зелёный индикатор |
| `port is already allocated` или `address already in use` | Порт 5000 занят другой программой. Создай в папке проекта файл `.env` с одной строкой `APP_PORT=5001`, снова запусти `docker compose up --build` и открывай http://localhost:5001 |
| `command not found: docker` или `git` | Программа не установлена, вернись к шагу 1 или 2 |
| Сайт не открывается, а терминал уже остановился | Смотри последние строки в терминале. Если там ошибка — скопируй её и покажи тому, кто помогает с проектом |
| После обновления проекта нет подсветки SQL или кнопки «⚙ Настройки» | Запусти `docker compose up --build`, затем обнови страницу с очисткой кэша: `Ctrl + F5` (macOS: `Cmd + Shift + R`) |
| Ничего не помогает | Введи `docker compose down`, затем `docker compose up --build` — так начнётся всё заново |

## Подсветка SQL и цвета

Запрос в терминале, эталонный запрос и результат подсвечиваются
цветами. Цвета можно поменять под себя: кнопка **«⚙ Настройки»** в
правом верхнем углу открывает окно, где для каждого вида слов
(ключевые слова, строки, числа, группы функций PostgreSQL и т. д.)
выбирается свой цвет. Изменения сразу применяются и **запоминаются
в браузере** — после `docker compose down` и нового запуска они
останутся. Кнопка `↺` рядом с цветом возвращает стандартный,
«Сбросить всё» — всю палитру.

## Подсказка по схеме

На вкладке **«Схема»** можно кликнуть по таблице или колонке — её
название вставится в терминал с запросом, туда, где стоит курсор.
Печатать длинные названия вручную не нужно.

## Полезно знать

- Пароли и настройки менять **не нужно**: всё работает «из коробки».
  Файл `.env` создавать необязательно.
- Учебная база данных создаётся заново при каждом запуске: сломать её
  запросами нельзя, всё вернётся в исходное состояние.
- Карточки, которые ты создашь или изменишь на сайте, после
  `docker compose down` пропадут. Остаются только 10 стандартных
  карточек, которые лежат в проекте.
- Если ты поменял что-то в самом проекте (например, добавил файл
  карточки в папку `cards/`), запускай с `--build`:
  `docker compose up --build`.

Подробнее о проекте — в `README.md`.
